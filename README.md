# BTJ Labs — Lead Pipeline for Curucaye

Everything specific to the BTJ Labs lead channel: leads generated by BTJ Labs'
Facebook/Instagram ads for Curucaye's AI services, imported into HubSpot after
BTJ's 10-day booking window, then worked by an email + AI-voice-call cadence.

## The pipeline

1. **Intake** — BTJ Automations Bot posts each lead into the Slack channel
   `#curucaye-btj-notifs` (`C0B4KLHBTHQ`). Leads older than 10 days are imported
   into HubSpot (contact, source "BTJ Labs", owner David Clunes Sr.; a deal only
   when BTJ booked an appointment). Runs daily at 9 AM ET via a Claude routine.
2. **Follow-up cadence** — 4 emails (from dclunessr@curucaye.com, offering the
   free 30-minute AI Opportunity Assessment) + 4 calls by **Matthew**, the
   Retell outbound sales agent, over 17 days. Stops on reply, booking, or opt-out.

The runnable skill definitions live in the `claude-agent-skills` repo
(`skills/btj-labs-lead-intake`, `skills/btj-labs-lead-followup`) — the Claude
environment loads skills from there. This repo holds the BTJ-specific code and
infrastructure.

## Phase 2 — live inbound scheduling (functions/)

`functions/` is a Firebase codebase (`btj`) deployed into the existing
`website-redesign-sales-agent` project so it shares that project's secrets
(`MS_TENANT_ID`, `MS_CLIENT_ID`, `MS_CLIENT_SECRET`, `HUBSPOT_API_KEY`).
`matthewInboundWebhook` answers Retell's call_inbound event: looks the caller
up in HubSpot by phone, computes David's LIVE availability from Graph (same
busy rule as the cadence), and returns Matthew Inbound + dynamic variables so
inbound callers can schedule on the call exactly like outbound. Failures
degrade to empty variables; the prompt then falls back to taking preferences.

Deploy (from a machine with Firebase access):

```bash
cd functions && npm install
npx firebase-tools login          # once
npx firebase-tools deploy --only functions:btj --project website-redesign-sales-agent
# then point the number at the printed function URL:
RETELL_API_KEY=... node ../scripts/bind-inbound-webhook.mjs <function-url>
```

Deploy ONLY with `--only functions:btj` — a bare deploy would touch the
redesign project's other resources.

## Provisioning / updating Matthew

```bash
RETELL_API_KEY=<key from Retell dashboard> node scripts/provision-matthew.mjs
# or put the key in .env (see .env.example); --dry-run prints payloads only
```

Run from a machine with open network access (the Claude cloud sandbox blocks
api.retellai.com). After any prompt change, the script re-publishes — required
for changes to serve. Patterns follow `claude-agent-skills/skills/retell-voice-agent`
(the playbook distilled from building Brooke and Cassie).
